  <action>
Replace the stub in `src/commands/clone.rs` with the full clone command.

**Flow per D-12, D-13, D-14:**

1. **Validate input file per D-13:**
   a. Check file exists: `args.audio_file.exists()` -- bail with clear error if not.
   b. Check extension is `.mp3` or `.wav` (case-insensitive): `path.extension().map(|e| e.to_ascii_lowercase())`. Bail if not MP3/WAV.
   c. Check file size is non-zero.
   d. If WAV, read with `hound::WavReader::open()` to check:
      - Duration: `total_duration = spec.channels * samples / sample_rate`. Warn (eprintln, not error) if < 1 second or > 30 seconds: "Warning: Reference audio is {duration:.1}s. Best results are with 3-10 seconds of clean speech."
      - Sample rate: warn if not 16000 or 24000 or 44100 or 48000: "Warning: Unusual sample rate ({sr}Hz). Best results with 16kHz-48kHz."
   e. For MP3 files, skip detailed validation (we don't have an MP3 decoder). Just check file size > 1000 bytes as a sanity check.

2. **Resolve profile name per D-08:**
   If `--name` provided, use it. Otherwise, slugify the source filename (without extension): `slugify(audio_file.file_stem().to_str(), 4)` then `unique_profile_name(slug)`.

3. **Resolve language:** Map `cli::Language` to string. `Auto` -> `"auto"`.

4. **Show spinner per UX-03:** `ui::create_spinner("Cloning voice from reference audio...")`

5. **Generate preview sample:** Call `bridge::voice_clone_from_audio(&audio_file, PREVIEW_SENTENCE, &language_str)` to generate the preview audio using the reference file directly.

6. **Create profile directory:** `profile::storage::profile_dir(&name)?`, `create_dir_all`.

7. **Save clone prompt per D-07:** Call `bridge::create_and_save_clone_prompt(&audio_file, PREVIEW_SENTENCE, &profile_dir)`. This saves `voice_prompt.bin` (CUDA/MPS) or copies ref audio as `ref_audio.wav` (MLX).

8. **Encode preview to sample.mp3:** `audio::samples_f32_to_i16(&wav)` then `audio::encode_wav_to_mp3(&pcm, sr, &profile_dir.join("sample.mp3"))`.

9. **Finish spinner.**

10. **Build and save ProfileMetadata per D-06:**
    - `name`: resolved name
    - `profile_type`: `ProfileType::Cloned`
    - `language`: language string
    - `description`: None
    - `source_audio`: Some(audio_file path as string)
    - `created`: `chrono::Utc::now().to_rfc3339()`
    - `model_variant`: backend-appropriate variant string for CustomVoice model
    - `sample_text`: PREVIEW_SENTENCE
    - `sample_rate`: sr from inference

11. **Call `profile::storage::save_profile(&metadata)`.**

12. **Unload models:** `bridge::unload_all_models()`.

13. **Print success per D-12 (no interactive loop):**
    ```
    Voice profile 'name' saved.
    Sample audio: /path/to/profiles/name/sample.mp3
    ```

**No interactive preview loop** per D-12 -- clone is deterministic. Just save and report.
