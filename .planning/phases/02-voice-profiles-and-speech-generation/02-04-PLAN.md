Replace the stub in `src/commands/generate.rs` with the full generate command.

**Flow per D-15, D-16, D-17, D-18, GEN-01, GEN-05, GEN-06:**

1. **Get text input:** For Phase 2, only inline text is supported (`args.text`). If `args.text` is None and `args.file` is None, bail with: "Provide text to speak, e.g.: chatter generate \"Hello world\" --profile myvoice". If `args.file` is Some, bail with: "File input is not yet supported. It will be available in a future update." (Phase 3 scope).

2. **Load profile:** Call `profile::storage::load_profile(&args.profile)`. On error, bail with: "Profile '{name}' not found. Run `chatter profiles list` to see available profiles."

3. **Get profile directory:** `profile::storage::profile_dir(&args.profile)?`

4. **Resolve language per GEN-06:** If `global.language` is not `Language::Auto`, use it (override profile default). Otherwise, use `profile.profile.language`. Map the `Language` enum to a lowercase string for Python.

5. **Resolve output path per D-15:**
   If `args.output` is Some, use it. Otherwise, generate default:
   ```rust
   let timestamp = chrono::Local::now().format("%Y%m%d-%H%M%S");
   let filename = format!("{}-{}.mp3", profile.profile.name, timestamp);
   PathBuf::from(&filename)  // writes to CWD
   ```

6. **Check output file exists per D-16:** If output path exists, print warning:
   ```
   "Warning: Overwriting existing file: {output_path}"
   ```
   Use owo_colors yellow for "Warning:" with `if_supports_color`.

7. **Show spinner per D-17 and UX-02:** `ui::create_spinner("Generating speech...")`. Research found no granular progress callbacks in qwen-tts, so use spinner + elapsed time (fallback per D-17).

8. **Call inference:** `bridge::generate_speech(&text, &language_str, &profile_dir)` -- returns `(Vec<f32>, u32)`.

9. **Finish spinner.**

10. **Encode to MP3 per GEN-05:** `audio::samples_f32_to_i16(&wav)` then `audio::encode_wav_to_mp3(&pcm, sr, &output_path)`.

11. **Unload models:** `bridge::unload_all_models()`.

12. **Print success:**
    ```
    Generated: {output_path} ({file_size_formatted})
    ```
    Calculate file size from `fs::metadata(&output_path)?.len()`. Format as KB or MB.

13. **Play audio per D-18:** If `args.play` is true, call `audio::playback::play_audio(&output_path)`.

**Error handling:**
- If profile directory is missing voice data files (no `voice_prompt.bin` and no `ref_audio.wav`), bail with: "Profile '{name}' is missing voice data. Try recreating it with `chatter design` or `chatter clone`."
- Wrap inference errors with context: `.context("Speech generation failed")`
- Wrap encoding errors with context: `.context("MP3 encoding failed")`
