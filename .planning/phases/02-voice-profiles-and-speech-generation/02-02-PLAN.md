Replace the stub in `src/commands/design.rs` with the full design command implementation.

**Flow per D-09, D-10, D-11, D-14:**

1. **Resolve profile name:** If `--name` provided, use it. Otherwise, `slugify(description, 4)` then `unique_profile_name(slug)`.
2. **Resolve language:** Map `cli::Language` to string for Python. `Language::Auto` maps to `"auto"`.
3. **Show spinner:** `ui::create_spinner("Loading VoiceDesign model and designing voice...")`
4. **Call inference:** `bridge::voice_design(PREVIEW_SENTENCE, &language_str, &description)` -- returns `(Vec<f32>, u32)`.
5. **Encode preview to temp MP3:** Create a temp file in the profile directory (create it early). Use `audio::samples_f32_to_i16(&wav)` then `audio::encode_wav_to_mp3(&pcm, sr, &temp_path)`.
6. **Finish spinner.** Print "Preview of your custom voice..."
7. **Play preview:** `audio::playback::play_audio(&temp_path)` per D-09.
8. **Interactive loop per D-10:**
   ```
   print!("Accept this voice? [Y/n/new description] ");
   io::stdout().flush()?;
   let mut input = String::new();
   io::stdin().read_line(&mut input)?;
   match input.trim() {
       "" | "y" | "Y" | "yes" => break (accept),
       "n" | "N" | "no" => bail!("Voice design cancelled by user"),
       new_desc => {
           description = new_desc.to_string();
           // Loop back to step 3 (re-run voice_design with new description)
       }
   }
   ```
9. **On accept -- save profile per D-05, D-06, D-07:**
   a. Create profile directory: `profile::storage::profile_dir(&name)?` and `create_dir_all`.
   b. Save WAV samples to a temp WAV file in profile dir (needed for clone prompt creation). Use `hound::WavWriter` to write the f32 samples to `ref_audio.wav` in profile dir.
   c. Call `bridge::create_and_save_clone_prompt(&ref_wav_path, PREVIEW_SENTENCE, &profile_dir)` -- this saves `voice_prompt.bin` (CUDA/MPS) or keeps `ref_audio.wav` (MLX).
   d. Encode the accepted WAV to `sample.mp3` in profile dir.
   e. Determine model variant string: detect backend, then use `"mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-bf16"` for MLX, `"Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign"` for others.
   f. Build `ProfileMetadata` with:
      - `name`: resolved name
      - `profile_type`: `ProfileType::Designed`
      - `language`: language string
      - `description`: Some(original description)
      - `source_audio`: None
      - `created`: `chrono::Utc::now().to_rfc3339()`
      - `model_variant`: variant string
      - `sample_text`: PREVIEW_SENTENCE
      - `sample_rate`: sr from inference
   g. Call `profile::storage::save_profile(&metadata)`.
   h. Call `bridge::unload_all_models()` to free memory.
10. **Print success message:** "Voice profile '{name}' saved to {profile_dir}/". Include sample.mp3 path.

**Important implementation details:**
- Use `std::io::{self, Write, BufRead}` for stdin interaction
- Use `hound::WavWriter` to write f32 samples to WAV (needed for clone prompt input): `WavSpec { channels: 1, sample_rate: sr, bits_per_sample: 32, sample_format: hound::SampleFormat::Float }`
- Keep the model loaded across retries in the interactive loop (Python side caches it in `_models` dict, so calling `voice_design()` multiple times reuses the loaded model)
- On any error during inference, finish the spinner before returning the error
- Use `anyhow::Context` for error context on all fallible operations
