Define a struct to hold all diagnostic data:

```rust
pub struct SystemInfo {
    pub python_version: Option<String>,
    pub torch_version: Option<String>,
    pub qwen_tts_version: Option<String>,
    pub backend: Option<ComputeBackend>,  // reuse from runtime.rs

    pub hf_cache_path: Option<String>,
    pub hf_cache_size_gb: Option<f64>,
}
```

`pub fn get_system_info() -> SystemInfo`:
- Uses `Python::attach(|py| { ... })` to gather all info in ONE GIL acquisition (not multiple).
- Python version: `sys.version` (first line only).
- torch version: `importlib.metadata.version("torch")` -- lightweight, avoids heavy torch import.
- qwen-tts version: `importlib.metadata.version("qwen-tts")`.
- Backend: call `detect_backend()` from runtime.rs (reuse, don't duplicate).
- Disk space: `shutil.disk_usage("/")` for free space. Convert to GB.
- HF cache: check `os.environ.get("HF_HOME", os.path.expanduser("~/.cache/huggingface"))`.
- HF cache size: walk the `hub/` directory with `os.path.getsize` (approximate, cap at 5s).
- Each field is `Option<T>` -- any check that fails just returns None, never crashes the whole report.

NOTE: `detect_backend()` already acquires the GIL internally. To avoid nested GIL issues, either:
1. Inline the backend detection logic within the same `Python::attach` closure, OR
2. Call `detect_backend()` separately outside the main closure (PyO3 0.28 allows re-entrant GIL).
Choose option 1 for cleaner code.

```rust
use indicatif::{ProgressBar, ProgressStyle};
use owo_colors::{OwoColorize, Stream};
use std::time::Duration;

/// Create a spinner with elapsed time display per D-07, D-08
pub fn create_spinner(message: &str) -> ProgressBar {
    let pb = ProgressBar::new_spinner();
    pb.set_style(
        ProgressStyle::with_template("{spinner:.cyan} {msg} ({elapsed})")
            .expect("valid template")
            .tick_strings(&["⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"]),
    );
    pb.set_message(message.to_string());
    pb.enable_steady_tick(Duration::from_millis(100));
    pb
}

/// Print error to stderr with colored prefix per D-05, D-06
pub fn print_error(msg: &str, verbose_detail: Option<&str>, verbose: bool) {
    eprintln!(
        "{} {msg}",
        "Error:".if_supports_color(Stream::Stderr, |t| t.red().bold())
    );
    if verbose {
        if let Some(detail) = verbose_detail {
            eprintln!("{detail}");
        }
    }
}

/// Print a pass item for doctor output
pub fn doctor_pass(label: &str, detail: &str) {
    println!(
        "  {} {label}: {detail}",
        "✓".if_supports_color(Stream::Stdout, |t| t.green().bold())
    );
}

/// Print a fail item for doctor output
pub fn doctor_fail(label: &str, detail: &str) {
    println!(
        "  {} {label}: {detail}",
        "✗".if_supports_color(Stream::Stdout, |t| t.red().bold())
    );
}

/// Print a warning item for doctor output
pub fn doctor_warn(label: &str, detail: &str) {
    println!(
        "  {} {label}: {detail}",
        "!".if_supports_color(Stream::Stdout, |t| t.yellow().bold())
    );
}
```
