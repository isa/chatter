Create `src/bridge/error.rs` using thiserror:
```rust
#[derive(Debug, thiserror::Error)]
pub enum BridgeError {
    #[error("Python error: {0}")]
    Python(#[from] pyo3::PyErr),

    #[error("qwen-tts is not installed. Install it with: pip install qwen-tts")]
    QwenTtsNotInstalled,

    #[error("Python runtime not found. Ensure Python 3.12 is installed")]
    PythonNotFound,

    #[error("No GPU available. Chatter requires Apple Silicon (MLX/MPS) or a CUDA GPU")]
    NoGpuAvailable,

    #[error("Model not found: {0}")]
    ModelNotFound(String),

    #[error("{0}")]
    Other(String),
}
```

Create `src/bridge/runtime.rs`:
- `pub enum ComputeBackend { Cuda { name: String, vram_bytes: u64 }, Mlx { memory_bytes: u64 }, Mps, Cpu }`
- `pub fn detect_backend() -> Result<ComputeBackend, BridgeError>` that uses `Python::attach(|py| { ... })` to:
  1. Import torch, check `torch.cuda.is_available()` -- if true, return `Cuda` with device name and VRAM
  2. Try `import mlx.core as mx`, check `mx.metal.is_available()` -- if true, return `Mlx` with memory from `mx.metal.device_info()`
  3. Check `torch.backends.mps.is_available()` -- if true, return `Mps`
  4. Return `Cpu` (caller decides whether to error)
- Priority order per D-11: CUDA > MLX > MPS > CPU
- Handle import errors gracefully: if torch not installed, return `BridgeError::QwenTtsNotInstalled`
- If mlx import fails, skip to MPS check (MLX is optional)

Create `src/bridge/model.rs`:
- Define model ID mapping function:
  ```rust
  fn model_repo_id(size: &ModelSize, variant: &str) -> String
  ```
  Maps (size, variant) to HuggingFace repo IDs like `"Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice"`. Variants: "VoiceDesign" (1.7B only), "CustomVoice", "Base".

- `pub struct ModelInfo { pub repo_id: String, pub size_label: String, pub local_path: Option<String>, pub size_bytes: Option<u64> }`

- `pub fn download_model(size: &ModelSize) -> Result<(), BridgeError>`:
  Uses `Python::attach` to call `huggingface_hub.snapshot_download(repo_id=...)` for all variants of the given size. Uses the default HF cache location. Returns errors if download fails.

- `pub fn list_cached_models() -> Result<Vec<ModelInfo>, BridgeError>`:
  Uses `Python::attach` to call `huggingface_hub.scan_cache_dir()`. Iterates over repos, filters those matching `Qwen/Qwen3-TTS-12Hz-*`, extracts repo name, size on disk, and local path.

- `pub fn remove_model(size: &ModelSize) -> Result<(), BridgeError>`:
  Uses `Python::attach` to call `huggingface_hub.scan_cache_dir()`, find matching revisions, and call `delete_revisions()` on the cache info object.

IMPORTANT per research:
- Use `Python::attach(|py| { ... })` NOT `Python::with_gil` (renamed in PyO3 0.28)
- Use `py.import("module_name")` to import Python modules
- Use `PyDict::new(py)` for kwargs
- Handle `PyImportError` specifically for missing packages: `err.is_instance_of::<pyo3::exceptions::PyImportError>(py)`
