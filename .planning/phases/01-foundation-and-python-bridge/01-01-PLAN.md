Create `src/cli.rs` with the full CLI type hierarchy using clap derive:

1. `Cli` struct with `#[command(name = "chatter", version, about = "Text-to-speech from the terminal, powered by Qwen3-TTS")]`, containing:
   - `#[command(flatten)] pub global: GlobalArgs`
   - `#[command(subcommand)] pub command: Commands`

2. `GlobalArgs` struct with:
   - `--verbose` (bool, `global = true`, env = "CHATTER_VERBOSE")
   - `--language` (Language enum, `global = true`, default_value_t = Language::Auto)
   - `--model-size` (ModelSize enum, `global = true`, default_value_t = ModelSize::B1_7)

3. `Language` enum deriving `ValueEnum` with 11 variants per FOUN-03: Auto, Chinese, English, Japanese, Korean, French, German, Spanish, Portuguese, Russian, Italian.

4. `ModelSize` enum deriving `ValueEnum` with per FOUN-04:
   - `#[value(name = "0.6b")] B0_6`
   - `#[value(name = "1.7b")] B1_7`

5. `Commands` enum with variants: Design(DesignArgs), Clone(CloneArgs), Generate(GenerateArgs), Profiles { command: ProfilesCommands }, Model { command: ModelCommands }, Doctor.

6. Arg structs for each command:
   - `DesignArgs`: `description: String` (positional), `--name: Option<String>`
   - `CloneArgs`: `audio_file: PathBuf` (positional), `--name: Option<String>`
   - `GenerateArgs`: `text: Option<String>` (positional), `--file: Option<PathBuf>`, `--profile: String` (required), `--output: Option<PathBuf>`
   - `ProfilesCommands` enum: List, Show { name: String }, Delete { name: String, #[arg(short = 'y', long)] yes: bool }
   - `ModelCommands` enum: Download { #[arg(value_enum, default_value_t = ModelSize::B1_7)] size: ModelSize }, List, Remove { #[arg(value_enum)] size: ModelSize }

Each command variant MUST have a doc comment (triple-slash) that appears in --help output per D-04 and UX-04. Example: `/// Design a voice profile from a natural language description`.

IMPORTANT per research: `global = true` goes on each `#[arg(...)]` inside GlobalArgs, NOT on `#[command(flatten)]`.
