**`detect_backend()`** (per D-01, D-03):
- Call `_check_deps()` first
- If `_variant != "multilingual"` (no MLX multilingual model exists -- Pitfall 4):
  - Try `import mlx.core as mx; if mx.metal.is_available(): return "mlx"`

- Try `if hasattr(torch.backends, "mps") and torch.backends.mps.is_available(): return "mps"`
- Fallback: `return "cpu"`
- Cache in `_backend_cache`. IMPORTANT: Reset `_backend_cache = None` when `_variant` changes (because MLX availability depends on variant)

**`set_mlx_quantization(suffix)`**: No-op for ChatterBox (no quantization variants). Just `pass`.

**`set_variant(variant_str)`** (new, ChatterBox-specific):

- If variant changes from current `_variant`:
  - Set `global _variant = variant_str`
  - Reset `_backend_cache = None` (backend may change between MLX/MPS for multilingual)
  - Call `unload_all_models()` (model class differs per variant)

**`_mlx_model_id()`** (private):
- If `_variant == "original"`: return `"mlx-community/chatterbox-fp16"`
- If `_variant == "turbo"`: return `"mlx-community/chatterbox-turbo-fp16"`
- If `_variant == "multilingual"`: raise ValueError (no MLX multilingual model)

**`_load_pytorch_model(variant, device)`** (private, per Pitfall 1 -- MPS safe pattern):
- Always load to `"cpu"` first, then selectively `.to(device)`:
  ```python
  if variant == "turbo":
      from chatterbox.tts_turbo import ChatterboxTurboTTS
      model = ChatterboxTurboTTS.from_pretrained("cpu")
  elif variant == "multilingual":
      from chatterbox.mtl_tts import ChatterboxMultilingualTTS
      model = ChatterboxMultilingualTTS.from_pretrained("cpu")
  else:
      from chatterbox.tts import ChatterboxTTS
      model = ChatterboxTTS.from_pretrained("cpu")
  if device != "cpu":
      model.t3 = model.t3.to(device)
      model.s3gen = model.s3gen.to(device)
      model.ve = model.ve.to(device)
  return model
  ```

```python
def set_engine(name):
    """Switch the active engine module.

    Per D-09/D-10: automatically unloads the previous engine's models
    to prevent OOM on 16GB Macs. The --engine flag is the explicit
    intent signal -- no confirmation prompt needed.

    Args:
        name: Engine name ("qwen" or "chatterbox").
    """
    global _active_engine, _active_engine_name
    from chatter_bridge.engines import AVAILABLE_ENGINES
    if name not in AVAILABLE_ENGINES:
        raise ValueError(f"Unknown engine: {name!r}. Available: {list(AVAILABLE_ENGINES.keys())}")

    # Unload current engine before switching (D-09: full cleanup)
    if _active_engine is not None and _active_engine_name != name:
        try:
            _active_engine.unload_all_models()
        except Exception:
            pass  # Best-effort cleanup -- don't block engine switch

    _active_engine = importlib.import_module(AVAILABLE_ENGINES[name])
    _active_engine_name = name
```
