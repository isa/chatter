3. In `src/bridge/venv.rs`:
- Add `const CHATTERBOX_REQUIREMENTS: &str = include_str!("../../requirements/chatterbox.txt");`
- Add a public function `install_chatterbox_deps() -> Result<(), BridgeError>` that:
  a. Gets `venv_path()` to find the venv
  b. Gets the Python binary path from the venv
  c. First runs `pip install --no-deps chatterbox-tts==0.1.7` using `std::process::Command` with the venv pip
  d. Then writes `CHATTERBOX_REQUIREMENTS` to a temp file and runs `pip install -r <tempfile>` (this installs the curated deps, skipping chatterbox-tts itself since it's already installed)
  e. Also installs `mlx-audio>=0.2.8` separately (only on Apple Silicon -- detect via `cfg!(target_arch = "aarch64")` and `cfg!(target_os = "macos")`)
  f. Returns `Ok(())` on success or `BridgeError::Other(...)` with the pip stderr on failure
  g. Uses `Stdio::piped()` for stdout and `Stdio::piped()` for stderr to capture output, and `Stdio::inherit()` for stdout to show download progress
- Add a public function `is_chatterbox_installed() -> bool` that:
  a. Gets `venv_path()`, returns false if error
  b. Runs `<venv>/bin/python -c "import chatterbox"` similar to `is_venv_ready()`
  c. Returns true if exit code is 0
