### Cross-Phase Issues

1. **Doctor --fix uses wrong install path** — `src/commands/doctor.rs` calls local `install_chatterbox_via_pip()` (bare pip) instead of `bridge::venv::install_chatterbox_deps()` (curated --no-deps pipeline). On Apple Silicon, skips mlx-audio. On all platforms, installs ~200MB of unnecessary deps (gradio). Affects: MDL-02.

2. **Doctor --fix skips model download** — After installing the Python package, `--fix` never calls `bridge::model::download_model_chatterbox()`. Users must separately run `chatter model download --engine chatterbox`. Affects: MDL-02.

3. **Engine mismatch prompt blocks non-interactive environments** — `generate.rs:138` reads stdin without TTY detection. In CI/pipes/scripts, this hangs indefinitely. Affects: ENG-03.

4. **Phase 04 plan is obsolete** — Specifies `class QwenEngine` / `class ChatterBoxEngine` architecture. Codebase uses module-level functions. Cannot be executed as-written without breaking working code.
